# Ответы на контрольные вопросы

1. **Что такое командная строка?**  
   Это текстовый интерфейс для взаимодействия с операционной системой, позволяющий выполнять команды, запускать программы и управлять файловой системой без использования графического интерфейса.

2. **Перечислите основные команды управления файлами в командной строке:**  
   - `mkdir` (создание каталога)
   - `rm` / `del` (удаление)
   - `cp` / `copy` (копирование)
   - `mv` / `ren` (перемещение/переименование)
   - `cat` / `type` (просмотр содержимого)
   - `touch` (создание пустого файла)

3. **Перечислите команды вывода основной информации системы:**  
   - `uname -a` (версия ядра и ОС)
   - `date` / `time` (дата и время)
   - `whoami` (текущий пользователь)
   - `hostname` (имя хоста)
   - `df -h` (дисковое пространство)
   - `free -m` (оперативная память)

4. **Перечислите команды ввода/вывода файлов:**  
   - **Вывод:** `cat`, `less`, `more`, `head`, `tail`
   - **Ввод/запись:** `echo >`, `cat >>`, `tee`, перенаправление потоков `>` (перезапись), `>>` (добавление), `|` (конвейер)

5. **Возможно ли полноценное управление системой, пользуясь только командной строкой? Ответ обоснуйте.**  
   Да, возможно. Большинство серверных и встраиваемых систем (включая Raspberry Pi) управляются исключительно через CLI. Командная строка предоставляет доступ ко всем системным утилитам, настройкам сети, правам доступа, процессам и логам. Графический интерфейс часто является лишь надстройкой над теми же системными вызовами.

6. **Чем отличается командная строка Windows от командной строки MS-DOS?**  
   Командная строка Windows (`cmd.exe`) является эмулятором и обратно совместимой оболочкой, которая добавляет поддержку Unicode, длинные имена файлов, конвейеры, переменные среды и расширенный набор команд по сравнению с реальным MS-DOS. Кроме того, в современных Windows основным интерпретатором является PowerShell, а `cmd` оставлен для совместимости.

7. **Приведите примеры интерпретаторов команд в других операционных системах.**  
   - **Linux/Unix:** `bash`, `zsh`, `fish`, `sh`  
   - **Windows:** `cmd.exe`, `PowerShell`, `Windows Terminal`  
   - **macOS:** по умолчанию `zsh` (ранее `bash`)
